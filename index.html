ABOUT DRACULA
Autonomous AI QA & Security Platform

DRACULA is a next-generation autonomous testing platform that combines AI-powered analysis with headless browser automation to deliver comprehensive security, accessibility, and UI audits — in seconds.

WEBSITE SCANNER
Crawls up to 3 pages, captures screenshots, detects WCAG violations and security misconfigs.
REPO ANALYZER
Scans GitHub repos for CVEs, secret leakage, build failures and Docker misconfigurations.
SELF-HEALING
Auto-installs Playwright Chromium binaries if missing — zero downtime, always ready.
LIVE DASHBOARD
Real-time terminal logs, KPI gauges, security score and findings gallery update live.
Built with Playwright · FastAPI · Next.js 14 · Tailwind CSS v4
HELP & DOCS
Quick reference guide
🌐
Scanning a Website
Enter any public URL in the console (without https://), select crawl depth 1–3, toggle checks, then hit EXECUTE SCAN.
🐙
Analyzing a GitHub Repo
Switch to GIT REPO ANALYZER tab, enter username/repo format, enable desired checks and execute.
📊
Reading the Dashboard
KPI cards update after each scan. The gauge shows your global security score. Findings panel lists all reports with per-scan stats.
🎨
Themes
Toggle between Sakura Serenity (light) and Enterprise Minimalist (dark) using the theme switch. Preference is saved automatically.
